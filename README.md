# Islet

Островок в стиле Dynamic Island для Windows 10/11: статус Claude Code и Codex, разрешения в один клик, музыка и микшер, система, уведомления и маскот «Пузырь».

**Скачать:** последний установщик — в разделе [Releases](https://github.com/amedevop/islet-releases/releases/latest).
